# Security Policy

## Supported versions

The latest published `0.x` release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

- Use GitHub's **private vulnerability reporting**: <https://github.com/Ravikisha/JorvelJS/security/advisories/new>, or
- email the maintainer listed in `.github/CODEOWNERS`.

We aim to acknowledge within 48 hours and to ship a fix or mitigation before any
public disclosure. Please include a reproduction and the affected package +
version.

## Scope

`@jorvel/*` packages and the `jorvel` / `create-jorvel` CLIs. Issues in
generated example apps that stem from a JORVEL primitive are in scope.
