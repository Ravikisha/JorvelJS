# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## Our standards

Be respectful and constructive. Harassment, discrimination, and personal
attacks are not tolerated. Assume good faith; critique ideas, not people.

## Enforcement

Report unacceptable behavior to the maintainers listed in `.github/CODEOWNERS`
(or via GitHub private reporting). Maintainers may remove, edit, or reject
contributions, comments, and contributors that violate this Code of Conduct.

The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
